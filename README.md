# WaterClient

A research recovery and open-source reconstruction of WaterClient.

This repository contains the reconstructed WaterClient source, recovered from available WaterClient artifacts for research, preservation, and further development.

The current project targets **Minecraft 1.21.11** using **Fabric** and **Java 21**.

> This is an independent software recovery and compatibility project. It is not affiliated with, authorized by, sponsored by, or endorsed by the original WaterClient developers, Mojang Studios, or Microsoft.

## Status

The source has been reconstructed from available WaterClient material and may contain code originating from multiple revisions of the client.

The current source should not be assumed to perfectly represent any single original WaterClient release. Some functionality may be incomplete, inconsistent between revisions, or require further verification.

## Safety

The source was recovered through static inspection without executing the supplied WaterClient artifacts during reconstruction.

Static inspection identified expected Minecraft/Fabric functionality alongside network-facing integrations and hardware/integrity-related code.

This should **not** be interpreted as a malware clearance or guarantee of safety. Review the source before compiling or running it.

## Building

The recovered project configuration targets:

- Minecraft 1.21.11
- Fabric Loader 0.18.4
- Fabric API 0.141.3+1.21.11
- Java 21

The project has not yet been fully verified as independently buildable.

Build instructions will be added once the reconstructed source has been successfully built and tested.

## Recovery

This project exists to preserve WaterClient as readable, inspectable, and researchable source.

The reconstruction is based on the available WaterClient source material rather than an official upstream source repository. Differences from particular WaterClient releases may therefore exist.

Where something appears incomplete, incorrect, or inconsistent, it should be treated as part of the ongoing recovery rather than assumed to represent the behavior of the original client.
